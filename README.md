# Campus Connect

Campus Connect is a modern React.js campus portal project designed to showcase student life, events, gallery, registration, and contact information in a clean and responsive user interface.

## Project Overview

This project was built to help students and visitors explore:

- Upcoming campus events
- Academic and cultural highlights
- Gallery sections for different categories
- Registration and contact information
- A responsive single-page experience

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- JSON-based content data

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ZIYADalsh/Campus_Connect_React.js_project.git
```

2. Go to the project folder:

```bash
cd Campus_Connect_React.js_project
```

3. Open the app folder and install dependencies:

```bash
cd Campus_Connect
npm install
```

## Run the App

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
