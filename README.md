# Campus Connect

A modern and responsive **React.js campus portal** designed to present student life, campus events, gallery content, registration information, and contact details through a clean and user-friendly interface.

## 📋 Overview

**Campus Connect** is a single-page web application built with **React.js** and **Vite**. The project provides students and visitors with an interactive way to explore campus activities, upcoming events, academic and cultural highlights, and gallery content.

The project was developed as an educational and portfolio project to demonstrate modern frontend development, component-based architecture, responsive design, and client-side interaction.

## ✨ Features

- Responsive campus landing page.
- Upcoming campus events and event information.
- Event details displayed through interactive modals.
- Gallery with category-based filtering.
- Registration section for campus activities.
- Contact information and communication section.
- Smooth page navigation.
- Clean and user-friendly interface.
- Responsive layout for desktop, tablet, and mobile devices.
- JSON-based content organization.

## ⚙️ Requirements

Before running the project, make sure the following are installed:

- **Node.js**
- **npm**
- A modern web browser
- A code editor such as **Visual Studio Code** or another JavaScript IDE

Check your installed versions with:

```bash
node -v
npm -v
```

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/ZIYADalsh/Campus_Connect_React.js_project.git
```

### 2. Navigate to the Repository

```bash
cd Campus_Connect_React.js_project
```

### 3. Open the Application Directory

```bash
cd Campus_Connect
```

### 4. Install Dependencies

```bash
npm install
```

## ▶️ Run the Application

Start the Vite development server:

```bash
npm run dev
```

Vite will display the local development URL in the terminal. It is usually:

```text
http://localhost:5173
```

Open the URL in your browser to access the application.

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🧭 Application Sections

The Campus Connect interface is organized around the main needs of students and visitors:

### 🏫 Campus Overview

Introduces the campus and provides a central entry point to the portal.

### 📅 Events

Displays upcoming campus events and allows users to view additional event details through interactive interfaces.

### 🖼️ Gallery

Provides visual campus content organized into categories, allowing users to filter the displayed images.

### 📝 Registration

Provides information and an interface for registration-related activities.

### 📞 Contact

Provides contact information and a dedicated section for communication.
